# CS2 Multiplayer Mod

Setup and troubleshooting for multiplayer in Cities: Skylines II.

## Your first session { #start-here }

1. **Install the mod.** Add [CS2 Multiplayer Mod](https://mods.paradoxplaza.com/mods/150432/Windows) to an empty playset in Paradox Mods and enable it. Restart the game if prompted.
2. **Check everyone's setup.** Use the same game and mod versions, with matching gameplay DLC. Check [mod compatibility](mods.md) before adding other mods.
3. **Host or join.** Open Multiplayer in the main menu. If everyone plays on Steam, use [Steam Relay](steam-relay.md) and share the join code. For other PC editions or a local network, use a [direct connection](direct-connection.md).

The [getting started guide](getting-started.md) covers the requirements and installation in detail.
